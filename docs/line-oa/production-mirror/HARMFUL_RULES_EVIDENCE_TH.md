# Evidence — Harmful global rules ใน TEST

ตรวจวันที่ 14 สิงหาคม 2026 บนบัญชีที่มองเห็นเป็น `มะลิปัง TEST`

- ก่อนแก้: พบ `Default` เป็น Fixed response, Responds to anything sent in chat, Always และหน้ากฎแสดงปุ่ม `Deactivate` (แปลว่าเปิดอยู่)
- การแก้: ยืนยัน modal `Deactivate this response?` เฉพาะบัญชี TEST
- หลังแก้: เปิดหน้ากฎซ้ำและพบปุ่ม `Activate` (หลักฐาน authoritative ว่ากฎปิดแล้ว)
- `Add Friend`: ไม่พบในรายการ TEST และไม่ได้สร้าง
- `Facebook อั่งเปา`: ไม่พบในรายการ TEST และไม่ได้สร้าง
- `Menu`: ไม่พบในรายการ TEST และไม่ได้สร้าง เพราะข้อมูลเมนู/ราคายังไม่อนุมัติ
- จำนวน active global fixed-response rules หลังแก้: 0
- ไม่ได้ลบกฎ ไม่ได้แก้ content ไม่ได้ส่งข้อความ และไม่ได้เปิด customer chat

Production `มะลิปัง` ไม่ถูกแก้ไขระหว่างงาน mirror นี้
