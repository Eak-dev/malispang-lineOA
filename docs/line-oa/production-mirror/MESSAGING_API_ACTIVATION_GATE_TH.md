# Messaging API activation gate — มะลิปัง TEST

วันที่ตรวจ: 14 สิงหาคม 2026
สถานะ: **หยุดก่อนสร้าง Provider/Channel**

## สิ่งที่ตรวจยืนยันก่อนดำเนินการ

- ชื่อบัญชีบนหน้าจอเป็น `มะลิปัง TEST` ตรงทุกตัวอักษร
- ไม่พบชื่อบัญชี Production `มะลิปัง` เป็นตัวเลือกเป้าหมายบนหน้าจอ
- เลือก `New provider` เพียงรายการเดียว
- ชื่อที่กรอกคือ `MalisPang TEST Sandbox` ตรงทุกตัวอักษร
- ไม่มี Provider เดิมถูกเลือก
- สถานะ Messaging API ก่อนดำเนินการเป็น `Disabled`

## ผลหลังได้รับอนุมัติและกด Agree

ระบบ **ยังไม่สร้าง Provider หรือ Messaging API Channel ทันที** แต่เปิดหน้าต่างขั้นถัดไปชื่อ `Privacy Policy and Terms of Use` โดยมีรายละเอียดดังนี้:

- ช่อง Privacy Policy URL รูปแบบ `https://` — optional — สูงสุด 500 ตัวอักษร
- ช่อง Terms of Use URL รูปแบบ `https://` — optional — สูงสุด 500 ตัวอักษร
- ข้อความแจ้งว่าสามารถแก้ไขข้อมูลนี้ภายหลังได้
- ปุ่มถัดไปคือ `OK`
- มีปุ่ม `Cancel`

หยุดก่อนกด `OK` เพราะการอนุมัติที่ได้รับครอบคลุมการกด `Agree` และการสร้างทันทีถ้าระบบทำต่ออัตโนมัติ แต่ไม่ได้ครอบคลุมการยืนยันหน้าต่างเพิ่มเติมนี้

## สถานะที่ยืนยันได้ ณ จุดหยุด

- บัญชี: `มะลิปัง TEST`
- ชื่อ Provider ที่เตรียมไว้: `MalisPang TEST Sandbox`
- Provider ถูกสร้างแล้ว: **ยังไม่ยืนยัน/คาดว่ายังไม่ถูกสร้าง**
- Channel ถูกสร้างแล้ว: **ไม่**
- ชื่อ Channel: **ยังไม่แสดง**
- Messaging API: `Disabled`
- Webhook: ไม่ได้ตั้งค่าและไม่ได้เปิด
- Token/credential: ไม่ได้สร้าง ไม่ได้เปิดดู และไม่ได้บันทึก

## ขั้นอนุมัติถัดไปที่ต้องการ

คำอนุมัติแบบเจาะจง:

> ยืนยันให้เว้นช่อง Privacy Policy และ Terms of Use ว่างไว้ และกด `OK` เฉพาะบัญชี `มะลิปัง TEST` เพื่อเข้าสู่หน้าตรวจสอบ/สร้าง Provider และ Channel จากนั้นหยุดก่อนปุ่มยืนยันเพิ่มเติมทุกปุ่ม หากระบบสร้างทันทีให้หยุดทันทีหลังสร้าง ห้ามสร้าง Token ห้ามดู Channel Secret ห้ามตั้งหรือเปิด Webhook และห้ามแตะ Production

หากเจ้าของต้องการใช้ URL นโยบาย ต้องส่ง URL สาธารณะที่อนุมัติแล้วและอนุมัติการกรอกแยกต่างหากก่อนกด `OK`
