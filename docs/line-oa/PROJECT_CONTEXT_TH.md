# บริบทโครงการ MalisPang LINE OA Test/UAT

สถานะเอกสาร: Phase 0 — ฉบับรวมศูนย์สำหรับออกแบบและทดสอบเท่านั้น
วันที่จัดทำ: 13 สิงหาคม 2026
ขอบเขต: ไม่เชื่อมต่อ ไม่เปิดใช้ และไม่แก้ไข LINE OA หรือระบบจริง

## เป้าหมาย

ออกแบบ Phase 1 เป็นระบบช่วยพนักงานตอบลูกค้า ไม่ใช่บอตขายสินค้าอัตโนมัติ โดยแบ่งเป็น:

1. **Phase 1A — FAQ:** เมนู/ราคา สถานที่/รับสินค้า เวลาเปิด การเก็บรักษา อายุสินค้า ขายส่ง และส่งต่อพนักงาน
2. **Phase 1B — ตรวจสอบสินค้าร่วมกับพนักงาน:** บอตห้ามเดาสต็อก ต้องรอข้อมูลยืนยันที่ยังสด
3. **Phase 1C — ร่างออเดอร์และใบเสนอราคา:** เก็บข้อมูลขั้นต่ำ คำนวณด้วยโปรแกรม สถานะ `DRAFT` เท่านั้น

## หลักการสื่อสาร

- ภาษาไทย อบอุ่น สุภาพ จริงใจ กระชับ และพร้อมให้พนักงานคัดลอกส่ง
- ห้ามใช้ศัพท์เทคนิคในข้อความถึงลูกค้า
- ห้ามสร้างข้อมูลราคา โปรโมชั่น สต็อก สาขา การแพ้ การชำระเงิน หรือคะแนนสะสม
- ไม่ใช้แชตเก่าเป็นแหล่งข้อมูลจริง
- เมื่อเข้าสู่ `HUMAN_HANDOFF` ให้ตอบรับเพียงครั้งเดียว แล้วบอตเงียบจนพนักงานที่ได้รับอนุญาตปิดสถานะ

## สิ่งที่รายงานไว้แต่ยังตรวจสอบไม่ได้

- Production OA: `มะลิปัง`; Test OA: `มะลิปัง TEST`
- Test OA เคยถูกรายงานว่าสร้างแล้ว และ Production OA ไม่เปลี่ยน
- Messaging API, Webhook, chatbot, Rich Menu, auto-response, coupon, reward card และ payment integration เคยถูกรายงานว่ายังไม่เปิด
- คำอธิบาย Test OA ที่ตั้งใจใช้: `บัญชีทดสอบระบบเท่านั้น — ไม่รับออเดอร์ ไม่รับชำระเงินจริง`
- จากตัวอย่างแชตแบบไม่ระบุตัวตน: คำถามเมนู/ราคาเด่นประมาณ 30/40 และพบคำขอโทษอัตโนมัติที่ไม่จำเป็น 9 กรณี
- เคยมี Top 10 intents, คำตอบไทย, handoff rules, สถาปัตยกรรม Test OA และ 16 UAT แต่ไม่พบไฟล์เหล่านี้

## ขอบเขตข้อมูลจริง

แยกข้อมูลเป็นโดเมนที่มีเวอร์ชันและผู้อนุมัติ:

- Product catalog: รหัส ชื่อไทย หมวด ขนาด ราคา ช่วงมีผล สถานะ และผู้อนุมัติ
- Availability: วันธุรกิจ สาขา รหัสสินค้า จำนวน/สถานะ ผู้ยืนยัน เวลา และหมดอายุ
- Promotion catalog: รหัส ข้อความที่อนุมัติ ช่วงเวลา สาขา/สินค้า เงื่อนไข และสถานะอนุมัติ
- FAQ KB: intent คำตอบที่อนุมัติ วันที่มีผล เจ้าของ และสถานะทบทวน

รายการเมนูและราคา 39 บาทใน brief เป็นเพียงข้อมูลรอเจ้าของตรวจ ห้ามเผยแพร่หรือใช้ตอบลูกค้าก่อนอนุมัติ
